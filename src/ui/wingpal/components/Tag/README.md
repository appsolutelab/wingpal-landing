# Tag

Etichetta breve che collega un elemento a un calendario o a una categoria.

- Pallino da 8px nel colore del calendario (`cal-graphite`, `cal-sky`, `cal-coral`, `cal-plum`, `cal-moss`) e testo `ink` su `surface-sunken`: il colore non è mai sul testo.
- `tone="reminder"`: pillola `marigold` con testo `on-marigold`, solo per i promemoria.
- Testo di una o due parole. Più di tre tag per elemento sono troppi.
